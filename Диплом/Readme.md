Система автоматического реагирования на DDoS-атаки (Pet-проект / Диплом)

Стек: Python, SQLite, iptables, Nginx, Kali Linux.

Что реализовано:

Парсинг логов: Анализ access.log (Nginx), вычисление метрик (RPS, error_ratio, unique_paths) с использованием скользящего окна.

Детекция аномалий: Комбинированный подход (статистический Z-score + ML Isolation Forest).

Автоматическое реагирование (SOAR): Модуль блокировки подозрительных IP через iptables.

Безопасность: Поддержка Whitelist (защита от самоблокировки), режим Dry-run (тестирование без реальной блокировки), таймер авторазблокировки (через 300 сек).

Аудит: Логирование всех инцидентов и действий в базу данных SQLite.

Проект прошел тестирование на имитации массовых (100% детект) и распределенных (95% детект) атак.
